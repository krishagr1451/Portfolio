Recording instructions — quick checklist

1) Setup
- Recommended tools: OBS (free), QuickTime (mac), or built-in screen recorder
- Microphone: USB condenser or headset; record in quiet room
- Resolution: 1920x1080; 30fps

2) Scenes to prepare in OBS
- Figma scene (window capture)
- Editor scene (VS Code window)
- Browser scene (live site in Chrome)
- Title/Outro scene (infographic or card)

3) Recording tips
- Record narration in short phrases (one sentence per take)
- Use separate audio track if possible
- Keep each segment short; cut and stitch in editor

4) Editing
- Editor suggestions: CapCut (free), DaVinci Resolve (free), Premiere Pro
- Add on-screen captions and highlight boxes to show focus

5) Export settings
- Format: MP4 (H.264)
- Resolution: 1920x1080
- FPS: 30
- Bitrate: 6–10 Mbps

6) Submission
- Include: `docs/process-infographic.svg`, video MP4, `docs/video-script.md`, `docs/video-storyboard.md`
